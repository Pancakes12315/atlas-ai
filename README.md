# Atlas AI

Atlas AI is a full-stack AI-powered enterprise search platform that helps users search internal knowledge bases and receive context-aware answers generated by a local large language model (LLM).

Unlike a traditional keyword search engine, Atlas AI uses a Retrieval-Augmented Generation (RAG) pipeline to retrieve relevant company documents, build contextual prompts, and generate grounded AI responses using Llama 3.2 running locally with Ollama.

---

## Features

* AI-powered enterprise knowledge search
* Retrieval-Augmented Generation (RAG)
* Local LLM integration using Ollama (Llama 3.2)
* Spring Boot REST API backend
* React + TypeScript frontend
* Document retrieval and ranking
* Query expansion using synonym matching
* Context construction for grounded AI responses
* Prompt engineering pipeline
* AI confidence scoring
* Source attribution
* Reasoning summaries
* Recommended follow-up actions
* Responsive modern UI

## Running the Project

### Backend

```bash
cd backend
./mvnw spring-boot:run
```

Backend runs on:

```
http://localhost:8080
```

---

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Frontend runs on:

```
http://localhost:5173
```

---

### Start Ollama

```bash
ollama serve
```

Download the model (first time only):

```bash
ollama pull llama3.2:3b
```

## Example Workflow

1. User submits a search query.
2. Atlas AI retrieves the most relevant internal documents.
3. Documents are ranked by relevance.
4. Context is assembled from the top results.
5. A prompt is generated for the LLM.
6. Llama 3.2 generates a grounded response.
7. The frontend displays:

   * AI-generated answer
   * Confidence score
   * Supporting documents
   * Reasoning summary
   * Suggested follow-up actions

## Why I Built Atlas AI

Atlas AI was built to explore modern AI search systems and Retrieval-Augmented Generation architectures while strengthening my experience in full-stack software engineering, backend services, information retrieval, and local LLM integration.

The goal is to demonstrate how enterprise AI assistants can provide grounded, explainable answers by combining traditional search techniques with modern language models.
